TABLETOP MAP 0.4.0 - DM WINDOWS SETUP

1. Install Node.js 22.12.0 or newer from https://nodejs.org/en/download.
   Choose the Windows installer for your computer (usually x64).
2. Right-click the ZIP and choose Extract All. Put the complete folder in a
   writable local location such as Documents\TabletopMap-DM.
3. Open TabletopMap and double-click Start-TabletopMap.cmd. Keep its command
   window open during play. If the browser does not open, visit
   http://localhost:5180/ in Chrome or Edge. Stop with Ctrl+C after play.
4. Connect the table monitor and choose Extend these displays in Windows
   Settings. Keep the DM view on the laptop. Open the player display from
   the DM page and move that window to the table screen.
5. Map Setup prepares maps, grid, display and tokens. Game-Play provides
   reveal/cover, token movement/visibility, invitations, atmosphere and dice.
   Switching tabs preserves progress. Apply/Save edits before reloading.
6. Import a PNG/JPEG. Maps start covered. Select/import other maps privately;
   click Show to Players only when ready to change the shared table.
7. Before placing physical minis, calibrate grid size using README.md and
   measure a square with a ruler on the table screen. Fitting/resizing the
   map changes physical square size. Lock placement when satisfied.

CAMPAIGNS, SESSIONS AND REUSABLE PREPARATION
- Create named campaigns and sessions in Map Setup. New sessions continue
  campaign progress instead of resetting maps, fog or tokens.
- Switching campaigns blanks the table and turns phone access off. Show the
  intended map and enable Wi-Fi deliberately when ready.
- The reusable map library can resume this campaign's location or create a
  deliberate fresh covered copy. Other campaigns get independent progress.
- Named NPCs retain identity when moved between maps. Templates create
  independent tokens. Map groups and Go to map / floor provide private
  navigation; Show to Players controls when players see the selected map.
- The lower preview always shows the live player map. While preparing another
  map, use the private main canvas and Setup controls.

OPTIONAL TWO-MONITOR BORDERLESS WINDOWS DISPLAY
Browser display works without this installation. For two player monitors,
run TabletopMap\desktop\Install-Windows-Display.cmd once with internet.
Choose Windows display under Player display, select the two table screens,
and click Fill both table screens. Their Windows scaling must match and
screens must form a rectangle without gaps. Escape closes the native display;
Use Browser display instead returns to browser mode. Play works offline after
Node/browser and any optional runtime are installed.

UPGRADING OR TRANSFERRING AN EXISTING CAMPAIGN
- Export a session backup and stop the old app first.
- Extract 0.4.0 into a new folder. Before its first start, copy the COMPLETE
  old TabletopMap\data folder into its TabletopMap folder. Do not merge two
  campaigns/data directories. If TABLETOP_DATA is configured, keep that path.
- This package contains no maps, saved campaigns or private character links.
- Existing single-session saves become My campaign / Session 1 without losing
  fog, tokens or calibration. The original JSON is retained automatically as
  data\session.before-campaign-workspace-v1.json. Successful saves use schema 2;
  older app versions deliberately refuse that format. Keep a complete exported
  backup for recovery; restore-backup.js always creates a new directory.
- If using the optional Windows runtime in a new installation folder, run its
  installer once there. Player invitation addresses may change on a new PC.
